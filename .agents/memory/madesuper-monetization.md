# Made Super AI monetization (user-confirmed)

Model (confirmed via user_query after several rounds of clarification):

- Signed-in users with **no plan** get a **few free trial chat questions** — "Ask Me Anything" chat ONLY. After they run out, they must buy a plan.
- **Every other tool** (Social, Builder, Studio, Tools) is **paid** — visible but behind an upgrade wall.
- Plans grant **credits that deplete** (Replit-style): show usage, prompt to upgrade when low/out.
  - Basic $19.99/mo = 100 credits/mo (metered)
  - Pro $29/mo = unlimited
  - Business $79/mo = unlimited
  - Owner = free / unlimited
- The free trial allowance is **NOT** called "credits" — credits only exist once a user has a plan. Free = "trial".

**Why:** The user repeatedly pushed back on a generic "free tier" and on gating the chat entirely. The settled answer is: free chat trial → then pay; all other tools always paid; plans = depleting credits with upgrade nudges.

**How to apply:** Don't reintroduce a "free credits" concept for non-subscribers, and don't gate the Ask Me Anything chat behind full entitlement — only behind the trial limit. Keep all other tools entitlement-gated.
